# 03 · 实操篇：跑通你的第一次 MoE 训练

> 目标：4 条命令跑完整条流水线，并且看懂屏幕上每一行在说什么。
> 全部命令在 Windows Git Bash / Linux / Colab 都能直接用（Colab 前面加 `!`）。

---

## 0. 一句话流程图

```
语料 ──data_prep──► train.bin + val.bin（token 序列，二进制）
                      │
                      ├──train──► latest.pt（权重）+ log.csv（曲线）+ routing_history.jsonl（路由历史）
                      │                │                        │
                      │                └──analyze──► 利用率条形图 / 文体路由表 / 路由演化
                      │
                      └──inspect──► 这一句话里每个字被派给了哪个专家
```

数据只需造一次；训练可以反复跑、随时续训。

---

## 1. 第一条：造数据（约 3 秒）

```bash
python data_prep.py --source builtin --repeat 40 --tokenizer char --out_dir data/demo
```

- `--source builtin`：我手写的一段演示语料（**只有 948 个汉字**，用来秒级验证流程）
- `--repeat 40`：把它复制 40 份 → 约 3.8 万字符（不加就太少，会看到奇怪的曲线）
- `--tokenizer char`：**字符级**。每个汉字 = 1 个 token，不需要训练词表，把注意力全放在 MoE 上
- 产物：`data/demo/train.bin`、`val.bin`、`meta.json`

**判读**：终端会打印词表大小与实际 token 数。若提示"语料过小"，说明该加 `--repeat` 或换真语料了。

### 换成真语料（想看到漂亮的下降曲线时）

```bash
python data_prep.py --source hf --hf_dataset wikimedia/wikipedia --hf_config 20231101.zh \
  --max_mb 300 --tokenizer char --out_dir data/wiki
```

- 需要联网；`--max_mb 300` 表示只取约 300MB 中文维基正文（**免费额度下别贪大**）
- 也可以用自己的 txt：`--source local --path D:/corpus/我的语料.txt`

> ⚠️ **一项重要的诚实提醒**：`--source builtin` 那 3.8 万字符会被反复喂养，
> 模型很快就把它们**背下来**（我们实测 200 步 val 损失 0.0139，基本等于背诵）。
> 那适合"验证管道通不通"，**不能**用它判断模型学得好不好。要看泛化，必须换真语料。

## 2. 第二条：训练（本地 41 秒 / 免费 GPU 更快）

```bash
python train.py --preset L0 --data_dir data/demo --out_dir out_L0
```

常用开关（都可组合）：

| 开关 | 作用 | 什么时候用 |
|---|---|---|
| `--preset L0` | 用 L0 配置（10.6M 总参数，8 专家 top-2） | 一直用 |
| `--max_steps 200` | 训练步数 | 做实验时调小，正式跑调大 |
| `--dense` | **关掉 MoE**，变成同等激活参数的稠密模型 | 做对照实验 E1 |
| `--n_experts 16` | 改专家数量 | E5 |
| `--top_k 1` | 每个 token 只用 1 个专家 | E3 |
| `--n_shared 0` | 关掉共享专家 | E4 |
| `--aux_coef 0` | 关掉负载均衡损失 | E2（看塌缩） |
| `--resume` | 从 `out_dir/latest.pt` 继续训 | 断线、换机器 |
| `--gcs_prefix gs://你的桶/moe` | 每存档一次就同步到云端 | Kaggle/Colab 防丢 |

### 屏幕上每一行怎么读

```
step    200/200 | ce 0.0157 | ppl 1.0 | lr 1.00e-04 | 193.1k tok/s | aux 1.005 z 1.91（每层均值） | 利用率 min 0.102 max 0.153
```

| 字段 | 含义 | 正常范围 |
|---|---|---|
| `ce` | 交叉熵损失（预测下一个字的难度） | 一直降到平台。字符级中文从 ~5.8 起步 |
| `ppl` | 困惑度 = e^ce，更好读的写法 | 越小越好 |
| `lr` | 学习率（warmup 升温后余弦衰减） | 开头线性上升，最后降到峰值的 10% |
| `tok/s` | 吞吐量 | 本机 CPU/GPU 差异大，只用于横向对比 |
| `aux` | 均衡损失的**每层平均**值 | **≈1.0 健康**；>1.3 开始偏 |
| `z` | 门卫发烧计 | 缓慢变化（1~3 常见）；突然翻倍要警觉 |
| `利用率 min/max` | 所有层里最闲/最忙专家的份额 | max 不宜超过均匀值 3 倍 |

**这一步的判读要点**：ce 下降是必要的，**但不是充分的**。
MoE 特有的健康指标是 aux / z / 利用率这三项 —— 第 4 课专讲。

### 存档与续训

训练会定期写 `out_L0/latest.pt`。中断后再跑同一条命令加上 `--resume` 即可接着训；
`out_L0/log.csv` 是全程曲线（可用 Excel 打开），`routing_history.jsonl` 记录每次存档时的路由快照。

**免费算力注意**：Colab 免费版 12 小时上限、闲置约 90 分钟断线；Kaggle 会话上限 12 小时、每周 30 小时 GPU 配额。
所以把存档间隔调到 30–60 分钟，并把 `out_dir` 放到 Google Drive / Kaggle 的持久目录里。

## 3. 第三条：给路由做体检（约 5 秒）

```bash
python analyze.py --ckpt out_L0/latest.pt --data_dir data/demo --mode all
```

三种模式（`--mode util|domain|evolution|all`）：

- **util**：每层 8 个专家的负载条 + 路由熵 —— 就是训练日志里那几行的汇总版
- **domain**：拿 4 种文体的句子（故事 / 百科 / 代码 / 对话）分别过一遍，
  看**每层每个专家在不同文体上拿到的份额**。这是"专家是否真的分工"的证据

  ```
   层0          故事      百科      代码      对话
     专家0    11.5%   15.9%   41.4%   23.7%      ← 代码的 token 明显偏向专家 0
  ```

- **evolution**：读 `routing_history.jsonl`，画出各专家负载随训练推进的走势

**判读**：真实的好结果是"整体均衡，但局部有偏好"（比如某专家在代码上 40%）。
若 4 个文体下每个专家的数字都几乎一样，说明**专家没分化**（不是错，但等于白养了几个专家）。

## 4. 第四条：追踪一句话里每个字去了哪（约 3 秒）

```bash
python inspect_route.py --ckpt out_L0/latest.pt --data_dir data/demo --text "春天来了，河边的柳树发芽了"
```

输出形如：

```
token        层0      层1      层2      层3
春          3,0      0,3      7,2      1,5
天          4,1      ...
```

- 每个格子 = 这个字在该层被派给的两个专家 id
- `--mode chars` 还能列出"每个专家最爱接的字"，这是最直观的"专家专业化"证据

## 5. 放到免费 GPU 上跑（Colab / Kaggle）

```bash
# 0) 把整个 moe-zh-learn 文件夹传到 Colab/Kaggle（或从网盘/Dataset 挂载）
# 1) 装依赖（通常 torch 已预装，只需确认）
pip install -q torch numpy
# 2) 让存档落在持久目录，防止会话被踢
python train.py --preset L0 --data_dir data/demo --out_dir /content/drive/MyDrive/moe/out_L0 \
  --gcs_prefix gs://你的桶/moe     # 或 --out_dir 直接指向 Drive 目录
# 3) 断线后
python train.py --preset L0 --data_dir data/demo --out_dir /content/drive/MyDrive/moe/out_L0 --resume
```

T4 没有 bf16：脚本会自动选 fp16 + 梯度缩放；本机若支持 bf16 会优先用 bf16。

---

## 6. 跑完之后你该做什么

1. 打开 `out_L0/log.csv`，看 `val_ce` 曲线是"下降后平台"还是"一路贴着 0"（后者=背下来了）
2. 跑一遍 `analyze.py --mode all`，记住健康的样子
3. 进入第 4 课 `04-诊断篇-路由的四种病.md`，用 `--aux_coef 0` 亲手制造一次"病"，对比刚才的健康样本
