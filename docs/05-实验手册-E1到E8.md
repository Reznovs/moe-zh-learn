## E1 · 等激活参数下，稠密 vs MoE 谁更强？

- **你要验证的**：MoE 的存在理由是"同算力换更大容量"，那在小规模上能不能兑现？
- **我猜**：\______________________
- **命令**

```bash
python train.py --preset L0 --data_dir data/wiki --out_dir out_E1_moe   --max_steps 2000
python train.py --preset L0 --data_dir data/wiki --out_dir out_E1_dense --max_steps 2000 --dense
```

- **要记的数字**：总参数、激活参数、val_ce、tok/s
- **我们已有的实测（玩具语料，200 步，仅用于演示格式）**

| 配置 | 总参数 | 激活参数 | val_ce | 吞吐 |
|---|---|---|---|---|
| MoE | 10.65M | 4.36M | 0.0139 | ~200k tok/s |
| 稠密 | 4.35M | 4.35M | 0.0136 | **557k tok/s** |

- **判读**：玩具语料上两者打平（都背下来了），**实验无效**，必须换真语料重做。
  真语料上通常稠密略优——这一结果本身极有价值：它说明 MoE 的收益**需要数据和规模**才付得出来。
  顺带一个反直觉发现：**MoE 这轮慢了 2.7 倍**。MoE 的"快"来自"和等容量的稠密模型比"，
  而不是它天生更快（多了路由和多次专家调用）。
- **结论（跑完填）**：\______________________

## E2 · 负载均衡损失到底在防什么？

- **我猜**（三个指标里哪个会最先报警？）：\______________________
- **命令**

```bash
python train.py --preset L0 --data_dir data/wiki --out_dir out_E2_a0   --max_steps 2000 --aux_coef 0
python train.py --preset L0 --data_dir data/wiki --out_dir out_E2_a01  --max_steps 2000 --aux_coef 0.01
python train.py --preset L0 --data_dir data/wiki --out_dir out_E2_a10  --max_steps 2000 --aux_coef 0.1
```

- **要记的数字**：val_ce、aux、z、利用率 min/max、层3 路由熵
- **实测（玩具语料 200 步）**：见 `04-诊断篇` 第 1 节那张对照表 —— 关键结论是
  **loss 不报警（0.0132 甚至比 0.0139 更好），而 z 从 1.91 涨到 6.54**。
- **判读**：`aux_coef=0` 若看到负载条出现空格 + z 持续上升 ⇒ 塌缩确认；
  `aux_coef=0.1` 若熵贴满 2.079、文体表全平 ⇒ 推过头了（病例 B）。
  健康区间通常在 0.01~0.03。
- **结论**：\______________________

  top-2 多一个"副手"，门卫不容易一条路走到黑。

## E5 · 专家越多越好吗？（等激活、加倍容量）

- **我猜**：\______________________
- **命令**

```bash
python train.py --preset L0 --data_dir data/wiki --out_dir out_E5_e8  --max_steps 2000 --n_experts 8
python train.py --preset L0 --data_dir data/wiki --out_dir out_E5_e16 --max_steps 2000 --n_experts 16
```

- **要记的数字**：总参数、激活参数（**应该几乎不变**）、val_ce、利用率均匀值（变成 1/16=0.0625）
- **预期**：总参数几乎翻倍、算力不变（这就是 MoE 的卖点）；
  但在数据不足时 **val_ce 收益接近 0** —— 容量是需要数据去"填满"的。
  这就是我们前面算过的"免费算力上吃不到 MoE 红利"的实证版。
- **结论**：\______________________

## E8 · 学习率对路由的影响（塌缩的催化剂）


  lr 太小则收敛慢，短期内看不出差别。
