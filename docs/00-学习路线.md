# 00 · 学习路线：不看代码，也能把 MoE 学会

> 这套文档是给你（不想读代码的人）准备的。代码只负责跑，你负责**看现象、猜结果、对答案**。
> 全部实验都是"抄一条命令 → 看屏幕上的几行数字 → 在本文档的表格里填结论"。

---

## 一句话先说清 MoE 是什么

普通大模型里，每个词都要经过**同一个**"知识处理器"（FFN）；MoE 把这个处理器**复制成好几个**，
再装一个**门卫**（router），每个词只交给其中 2 个处理。于是：
模型总容量变大了，但每个词的计算量几乎没变。

**它换来的东西**：同样算力/时间，能塞进更多参数。
**它付出的代价**：显存要装下所有专家，路由要训练、要监控，不然会"偏科"。

---

## 为什么值得学（而不是只学稠密模型）

| | 稠密模型 | MoE |
|---|---|---|
| 每步计算量 | 全部参数都参与 | 只激活一部分（top-k） |
| 显存 | = 参数量 | = **全部**专家都要驻留 |
| 训练难点 | 收敛、数据 | 收敛 + **路由均衡** + 通信 |
| 出问题时 | 曲线难看 | 曲线好看但**专家饿死**，指标骗人 |

最后一行是重点：**稠密模型的问题写在脸上，MoE 的问题藏在路由里**。
学 MoE，真正学的是"怎么给一个会偷懒的模块做体检"。

## 这个项目本身是什么

- 位置：`moe-zh-learn/`（本项目文件夹）
- 模型：**中文、字符级、10.6M 参数的迷你 MoE**（8 个专家，每个 token 用 2 个 + 1 个共享专家）
- 硬件：**本地电脑或 Colab/Kaggle 免费 GPU** 都能跑。L0 预设跑 200 步只要 **41 秒**
- 目的：**不是**训练一个有能力的模型，而是**把 MoE 训练过程变成一个能看得见的东西**

所以你会看到比一般教程多得多得多的仪表盘输出：

```
step    200/200 | ce 0.0157 | ppl 1.0 | lr 1.00e-04 | 193.1k tok/s | aux 1.005 z 1.91（每层均值） | 利用率 min 0.102 max 0.153
    层0 专家负载 ▅▃▄▃▄▅▄▄  (均匀=0.125) 路由熵=1.883/2.079
    层1 专家负载 ▅▃▄▅▅▄▃▃  (均匀=0.125) 路由熵=1.656/2.079
```

这些行以后会天天见到。第 3 课逐个讲清楚。

## 学习建议（重要）

1. **一次只改一个变量**。MoE 的坑几乎都来自"我同时改了三样东西"。
2. **先写预测再跑实验**。实验手册里每道题都有"我的预测"一栏，写下来再去跑。跑完对答案，这才是学习。
3. **曲线好看≠训练正常**。第 4 课会给你一个反例：loss 掉得很漂亮，但一半专家已经饿死了。
4. **不要一上来就上真数据上大模型**。10M 的小模型 40 秒一轮，你能在一晚上做 50 次实验——这个迭代速度才是学习的关键。
   （等你要"看到一条漂亮的下降曲线"时，再换真语料；第 3 课末尾有命令。）
